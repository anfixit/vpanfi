# VPaNfi

Самостоятельный пользовательский кабинет и публичный сайт сервиса защищённого подключения. Маскот продукта — обезьянка Анфиса, которая помогает пройти через интернет-джунгли без технической путаницы.

![VPaNfi](assets/mascot/jungle.svg)

## Что уже реализовано

- адаптивная публичная главная;
- светлая и тёмная темы;
- тарифы 300 / 800 / 1 500 ₽;
- бесплатный период 7 дней;
- демонстрационный вход через логин, Telegram, Яндекс и VK;
- личный кабинет;
- подключение Android, iPhone/iPad, Windows, macOS, Linux, Android TV и Apple TV;
- HAPP как рекомендуемое приложение и альтернативные клиенты;
- QR-сценарий;
- устройства и платные дополнительные места;
- баланс, автопродление и история платежей;
- поддержка с демонстрационным чатом;
- профиль и связывание способов входа;
- основа небольшой админки;
- Docker и healthcheck;
- архитектурный и API-контракты будущего backend.

Сейчас данные демонстрационные. Реальные секреты, Remnawave, СБП, OAuth и AI-поддержка подключаются на серверном этапе.

## Быстрый запуск

Без Docker:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080`.

Через Docker:

```bash
docker compose up -d --build
curl http://127.0.0.1:8080/health
```

## Демонстрационный кабинет

Нажмите «Войти» и используйте любой способ. В демонстрационном режиме внешние провайдеры не вызываются.

Прямой адрес после создания сессии: `/#/app`.
