# Бот поддержки VPaNfi: замысел

Дата: 06.09.2026. Согласован с Анфисой в диалоге, здесь зафиксирован.

## Зачем

Поддержка VPaNfi это один человек. Обращения приходят в Telegram, MAX,
почту, тикеты продающего бота и форму на сайте, и почти все они про одно
и то же: не подключается, оплатил и потерял ссылку, превышено число
устройств, пополнил и не продлилось. Бот поддержки отвечает на такие
обращения сам, проверяет данные в панели и базах, выполняет безопасные
действия и зовёт Анфису только там, где нужен человек или деньги.

## Что решено

1. Два отдельных бота: Telegram и MAX. Одно ядро.
2. Кнопка «Поддержка» в Bedolaga и ссылки на сайте ведут в бота.
   Тикеты Bedolaga выключаются, открытые переносятся руками.
3. Бот делает всё сам, кроме денег. Каждое действие видно Анфисе в тот
   же момент.
4. Модель: Claude Opus 5 через API Anthropic, одна. GPT не используется.
5. Анфиса читает и отвечает в группе Telegram с темами: тема на клиента.
6. Тон: очень вежливо и приветливо, на «Вы», от первого лица, без
   длинных тире, объяснения по тому, что человек видит на экране.

## Устройство

### Компоненты

- **Входы.** Telegram (aiogram 3, вебхук) и MAX (официальная
  Python-библиотека max-botapi-python, вебхук `POST /subscriptions`).
  Оба принимают текст и картинки, отвечают в тот же канал.
- **Ядро.** Claude Opus 5 (`claude-opus-5`, адаптивное мышление,
  `output_config.effort: medium`, серверный `fallbacks: "default"`) с
  инструментами через SDK `anthropic` (tool runner). Системная часть:
  правила поведения, база знаний `docs/support-bot/knowledge-base.md`,
  эталоны объяснений. Всё это кэшируется (`cache_control`), волатильное
  идёт после точки кэша.
- **Инструменты чтения** (только по сопоставленной учётке):
  - панель Remnawave: учётка (статус, срок, тег, лимит устройств),
    устройства (HWID, модель, платформа, приложение и версия), трафик по
    дням и по узлам, последние запросы подписки (приложение, версия,
    IP и владелец сети), статус узлов;
  - база Bedolaga: баланс, тариф, автоплатёж, транзакции, статус в боте;
  - база сайта: кабинет, платежи, отправленные письма, тикеты формы;
  - определение сети по IP (домашний оператор, мобильный, хостинг).
- **Инструменты действий** (нужен скриншот из приложения, см. защиту):
  перевыпустить ссылку подписки; снять привязку устройства; поставить
  тариф и включить автопродление в Bedolaga; продлить срок, списав с
  баланса Bedolaga через его же логику. Денежных инструментов нет:
  возврат, зачисление на баланс, продление без оплаты бот не умеет
  физически.
- **Зеркало.** Группа Telegram с темами. На каждого клиента тема,
  название «Имя · канал · учётка». Туда идут: сообщения клиента, ответы
  бота, строки «сделал: ...», просьбы «нужны вы». Ответ Анфисы в теме
  уходит клиенту от бота.
- **База Postgres** бота: `people` (сопоставление Telegram ID, MAX ID,
  почта, учётка панели, id в Bedolaga, id темы), `messages` (диалог,
  канал, автор: клиент, бот, Анфиса), `actions` (журнал инструментов с
  входом и результатом), `holds` (кто на паузе и до чего), `escalations`.
- **Хостинг.** Контейнеры `vpanfi-support` и `vpanfi-support-db` на
  aeza-nl-bots рядом с Bedolaga, вебхуки через тот же Caddy. Репозиторий
  anfixit/vpanfi-support, деплой из GitHub Actions по образцу сайта.

### Опознание

1. Telegram ID или MAX ID совпал с учёткой в панели, Bedolaga или сайте:
   человек опознан.
2. Иначе бот просит ID из бота или почту из кабинета. По ним разрешены
   только общие данные: срок, число устройств, баланс, дата последнего
   подключения.
3. Для любого действия нужен скриншот из приложения с экраном подписки
   VPaNfi. Без него инструмент действия отказывает, бот объясняет, какой
   экран прислать.

### Поток сообщения

1. Вебхук кладёт сообщение в базу и в тему группы.
2. Если человек на паузе (Анфиса вмешалась или сказала `/стоп`), бот
   молчит.
3. Ядро получает последние 30 сообщений, карточку человека, базу знаний.
   Claude вызывает инструменты и отвечает. Картинки передаются как
   изображения.
4. Ответ уходит клиенту и в тему. Вызовы инструментов пишутся в
   `actions`, действия ещё и строкой в тему.

### Команды Анфисы в теме

- Текст: уходит клиенту от бота, бот ставится на паузу.
- `/дальше`: снять паузу.
- `/стоп`: бот молчит с этим человеком до `/дальше`.
- `/кто`: карточка человека и последние действия.

### Когда бот зовёт Анфису

Деньги в любом виде (возврат, «я заплатил, а…» без подтверждения в
кассе, просьба продлить бесплатно), злость или угрозы, просьба позвать
человека, третий заход по одной и той же проблеме, противоречивые
данные, отказ инструмента, Синергия (корпоративный клиент). Бот пишет в
тему «нужны вы: причина», клиенту «передала Анфисе, она ответит», и
молчит до её ответа. Анфиса получает уведомление только в этом случае.

### Защита

- Инструменты работают только по учётке из карточки; чужой ID без
  скриншота не даёт действий.
- Текст клиента для модели данные, не инструкции. Правила и база знаний
  лежат в системной части, клиенту не выдаются.
- Лимиты на человека: 30 сообщений в час, 3 действия в сутки, затем
  очередь к Анфисе.
- Клиенту не выдаются: IP, хостеры, внутренние имена узлов, данные
  других людей, токены. Ссылка подписки выдаётся только владельцу и
  только через перевыпуск.
- Секреты в `/root/vpanfi-support.env` на сервере, файл создаёт Анфиса.
  Доступ к базам Bedolaga и сайта только на чтение отдельными ролями.

### Сбои

- Нет ответа от Claude или панели: клиенту «проверяю, отвечу через
  несколько минут», повтор через минуту, после трёх неудач зов Анфисы.
- Бот упал: вебхуки Telegram и MAX повторяют доставку, при старте бот
  дочитывает пропущенное через `getUpdates`/`GET /updates` с последнего
  сохранённого маркера.
- Проба в мониторинге на kb, алерт в чат Анфисы. Ошибки бота тоже в чат.
- Бэкап базы в ночной скрипт `vpanfi-backup.sh` на aeza-nl-bots.

## Проверка

- Автотесты ядра с заглушками инструментов: опознание, отказ по чужому
  ID, лимиты, пауза и `/дальше`, зеркало, журнал действий.
- Набор из 30 реальных обращений из истории (Злата, Домненко, Юлия с
  балансом, Стас, Синергия, «оплатил и потерял ссылку») прогоняется через
  Claude; ответы читает Анфиса и правит базу знаний.
- Неделя тихого режима: бот отвечает только учёткам Анфисы и разработчика,
  клиентам молчит, в группе видно, что бы он ответил. Потом включение.

## Стоимость

Claude Opus 5, около 10 тысяч входных токенов на ответ (большая часть из
кэша) и 300 выходных: около 1,2 ₽ за ответ, около 1 100 ₽ в месяц при
30 ответах в день.

## Что нужно от Анфисы

1. Группа Telegram с включёнными темами, бот-администратор в ней.
2. Ключ API Anthropic (console.anthropic.com), баланс 20 долларов.
3. Токены ботов Telegram и MAX: не в чат, а в файл на сервере командой.

## Чего нет в первой версии

- Форма на сайте остаётся письмом, в группу не попадает.
- Бот не пишет клиентам первым; напоминания и рассылки остаются у
  Bedolaga и сайта.
- Голосовые сообщения не разбираются, бот просит текст.
- Второе мнение GPT.
- Веб-кабинет поддержки.
