# Approved Anfisa mascot set

The production interface must use the approved ten-state Anfisa set:

1. greeting
2. connection success
3. checking connection
4. working online
5. support
6. error
7. QR code
8. payment success
9. active subscription with banana
10. internet-jungle explorer

Temporary emoji and ASCII mascot placeholders are not allowed. The raster sprite is prepared from the approved source sheet and is added separately as a binary asset.
