# Исходники маскота

Десять исходных PNG от 27.07.2026, примерно по 1,7 МБ каждый. Из них сделаны
лёгкие `.avif` и `.webp` в `public/mascots/`, которые и показывает сайт.

Имена номерные: какой файл какому состоянию (`anfisa-greeting`, `anfisa-connected`,
`anfisa-error` и прочим) соответствует, по самим файлам не восстановить —
переименовать стоит, сверившись с картинками.

До этого лежали отдельной папкой в `~/dev` и ни в один репозиторий не входили.
